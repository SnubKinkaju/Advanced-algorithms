# Minimum Set Cover — Provisional Project Plan

**Date:** 5 November 2026  
**Team:** Mohamed, Badis, Rayan, Enes and Khairy

## Objective

Implement and compare algorithms for the unweighted Minimum Set Cover problem, using the approaches studied in class. Evaluate their running time and solution quality on generated instances and existing unweighted benchmarks.

## Milestones

The dates below are provisional and may be adjusted as the project progresses.

| Milestone | Planned period | Main tasks |
| --- | --- | --- |
| **M1 — Planning and organization** | 5 November | Agree on the project organization, define the roadmap and submit the group description and provisional planning. |
| **M2 — Algorithm development** | 6–29 November | Agree on shared implementation conventions. Each member develops at least one distinct algorithm. Integrate the implementations and perform initial correctness checks. Algorithm assignments will be decided later. |
| **M3 — Testing, experiments and analysis** | 30 November–14 December | Test correctness, run experiments, compare performance and solution quality, and explain the strengths and limitations of each method. Complete the report and prepare the final archive and presentation. |

The methods to cover are brute force, branch and bound, greedy, exact dynamic programming, another method of our choice, and an additional heuristic or metaheuristic. The additional methods and programming language will be selected later.

## Testing and evaluation

- Check solution validity and compare exact algorithms on small instances with known solutions.
- Use generated instances with different sizes and densities, together with existing unweighted benchmarks.
- Compare runtime and cover size under consistent experimental conditions, distinguishing proven optima from best-known solutions.
- Document the experimental setup and interpret the results in the report.
